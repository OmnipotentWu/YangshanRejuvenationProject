# Markdown 正文语法指南

后台（Sveltia CMS）的 Markdown 编辑器自带工具栏，本指南覆盖常用语法与本站的**扩展约定**。

## 一、基础语法

| 效果 | 写法 | 说明 |
|---|---|---|
| 小标题 | `## 章节名` | 一个 `#` 是档案大标题（已由表单提供），正文用 `##` / `###` |
| 加粗 | `**重要内容**` | |
| 斜体 | `*强调*` | |
| 引用 | `> 引文` | 渲染为左侧金线引用块 |
| 无序列表 | `- 项目`（每行一条） | |
| 有序列表 | `1. 项目` | |
| 分割线 | `---`（单独一行） | |
| 行内代码 | `` `代码` `` | |
| 表格 | 见下 | |

表格写法：

```markdown
| 列1 | 列2 |
|---|---|
| 内容 | 内容 |
```

## 二、插入图片

在后台编辑器中点 **图片** 按钮上传，或在正文中手写：

```markdown
![图片说明](/YangshanRejuvenationProject/uploads/202609/xxxx.png)
```

- 图片自动限宽，不会撑破档案框；
- 建议图片宽度不超过 1600px，单张 ≤5MB；
- 建议始终填写"图片说明"（alt），利于检索与无障碍。

## 三、档案间互相引用（自动内链）

直接用《书名号》写档案标题，前台会自动变成站内链接：

```markdown
详细机制见《雨夜》与《契科夫之枪》。
```

也支持以下写法（谬误类常用）：

```markdown
见于谬误条目'雨夜'、谬误-'祖师'、参见谬误《双塔》
```

> 链接目标按标题精确匹配（含识别代称，如《威士忌》）。标题以书名号原文为准。

## 四、首行缩进（本站扩展）

中文排版习惯段首空两格时，在段落开头输入 `>> `（两个大于号加空格）：

```markdown
>> 这一段会以首行缩进两字符渲染。
```

再写一遍去掉 `>> ` 即取消。注意：这个标记必须放在段首才生效。

## 五、各档案类型的正文组织建议

- **谬误备案**：七个小节（描述/危险性/利用性/可逆性/溯源/处置/参考报告）是独立字段，由表单维护；附记字段适合放小节之后的内容。
- **个体备案**：背景履历、外貌、谬误影响、持有物为独立字段；画廊在专门字段中上传排序。
- **势力情报 / 设定资料 / 仰山辞海**：正文就是一个 Markdown 字段，`## 小节` 切分章节。
- **首行缩进**适合设定资料与辞海的长段落；谬误备案的小节正文建议用标准段落，保持档案体风格统一。
